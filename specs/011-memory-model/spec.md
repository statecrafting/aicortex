# 011: The memory record

## 1. Purpose

The predecessor stored a row of text, a vector, and a free-form JSON bag
whose shape was defined only inside a prompt sent to a model, so no two
rows agreed and no query could rely on a field existing
(`openbrain://json-bag-schema`). This spec is the opposite: the shape is
types, the invariants are unrepresentable-if-violated, and the model that
extracts metadata proposes values into a fixed structure rather than
inventing one.

## 2. Territory

The `aicortex-types` crate. Every other crate depends on it and it depends
only on `rahi-types` and serde. It contains no I/O, no SQL, and no async.

## 3. Behavior

- **B-1 (identity).** `MemoryId` wraps a UUIDv7 so identifiers sort by
  creation time and index locality is good. Ids are generated by the
  writer, never by the database.
- **B-2 (scope).** `Scope { owner: Sub, kind: ScopeKind }` where
  `ScopeKind` is `Personal`, `Project(ProjectKey)`, or `Shared(ShareKey)`.
  `Sub` is rahi's, verbatim (constitution VII). Every read and write names
  a scope; there is no ambient or default scope, and no memory exists
  outside one.
- **B-3 (the record).** `Memory { id, scope, kind: MemoryKind, body:
  MemoryBody, actor: Actor, provenance: Provenance, trust: TrustClass,
  status: Status, importance: Importance, schema_version: u16, created:
  UnixSeconds, updated: UnixSeconds }`.
- **B-4 (kind).** `MemoryKind` is a closed enum: `Observation`, `Fact`,
  `Preference`, `Decision`, `Task`, `Reference`, `PersonNote`,
  `Correction`. Unknown values are a deserialization error, not a
  passthrough, so a model cannot widen the taxonomy by emitting a new
  string.
- **B-5 (trust).** `TrustClass` is `Evidence` (this happened and is
  recorded), `Assertion` (someone claims this is so), or `Instruction`
  (a client may act on this). `Instruction` is unconstructible from
  library code: `TrustClass::instruction(Promotion)` requires a `Promotion`
  token, and the only constructor of `Promotion` takes a human `Sub` and a
  rahi `DecisionId`. An agent therefore cannot promote its own memory in
  any code path, including one written later by a session that did not
  read this spec.
- **B-6 (status).** `Status` is `Active`, `Quarantined`, `Superseded(MemoryId)`,
  `Expired`, or `Erased`. Only `Active` is visible to retrieval by default.
  `Erased` rows retain the id, scope, and timestamps and nothing else: the
  body is gone, not blanked with a marker that could still carry content.
- **B-7 (actor).** `Actor { kind: ActorKind, id: ActorId, label }` where
  `ActorKind` is `Human`, `Agent`, `System`, or `Import`. An `Agent` actor
  carries the client and model that produced it when known.
- **B-8 (provenance, mandatory).** `Provenance { source: SourceRef,
  captured_at, ingested_at, derived_from: Vec<MemoryId>, extractor:
  Option<ExtractorVersion> }`. `Memory::new` takes a `Provenance` by value
  and there is no `Default` implementation for it, no builder that can
  finish without one, and no deserialization path that fills it in. A
  derived memory names every memory it came from.
- **B-9 (importance).** `Importance { base: f32, last_used: UnixSeconds,
  uses: u32 }` with a pure `decayed_at(now) -> f32` function. Decay is a
  computation, never a background write that rewrites rows.
- **B-10 (body).** `MemoryBody { text: String, title: Option<String>,
  media: Vec<MediaRef> }`. Text is the canonical form; media is referenced
  by content hash and lives outside the row.
- **B-11 (schema version).** Every record carries the version it was
  written under, so a migration can reinterpret old rows explicitly rather
  than by assumption (`openbrain://no-schema-management`).

## 4. Functional requirements

- **FR-001.** A round-trip test serializes and deserializes every fixture
  in `testdata/memories/` byte-identically.
- **FR-002.** A deserialization of an unknown `kind`, `trust`, or `status`
  string fails with a typed error naming the field.
- **FR-003.** A compile-fail test (trybuild) asserts that constructing
  `TrustClass::Instruction` without a `Promotion` does not compile, and
  that `Promotion::new` cannot be called with an `Actor` of kind `Agent`.
- **FR-004.** A test asserts `Memory` has no constructor reachable without
  a `Provenance`, by reflection over the public API surface in a doc test.
- **FR-005.** `decayed_at` is monotonically non-increasing in elapsed time
  and returns the base value at zero elapsed time (property test).

## 5. Acceptance criteria

- **AC-1.** `cargo test -p aicortex-types --locked` passes, including the
  compile-fail cases.
- **AC-2.** The crate has no dependency on any I/O, SQL, or async crate,
  asserted by a `cargo tree` test.

## 6. Out of scope

Persistence and the SQL shape (012), the gate that decides admission
(013), and the transitions between statuses (014). Entities and edges,
which are their own records (017).

## 7. Resolved decisions

- **D-1 (2026-09-03, this spec).** `Instruction` is made unconstructible
  rather than merely checked at the boundary. A runtime check lives in one
  place and is forgotten by the next session that adds a write path; a
  type that cannot be built is checked by the compiler on every path
  forever. This is the mechanism that makes constitution X hold.
